01 — HOW IT WORKS
01 · MOTION CURVE AND EVERY ELEMENT'S --p KEYFRAMES

Every ramp is r(a, b) = clamp(0, (p − a) / (b − a), 1). Opacity uses r directly. Position and size changes use the eased value s = r² (3 − 2r), which is one more calc() line. Only one thing moves per beat. The text-free gap from .26 to .36 is deliberate: it's the dusk beat, and text never crosses the sky while it changes colour, so contrast never drops below AA.
